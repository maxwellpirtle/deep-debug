# External Integrations

**Analysis Date:** 2026-08-08

## Process Management & Execution

**Linux Process System:**
- **Purpose:** Core process and thread lifecycle management
- **Mechanism:** Uses Linux system calls (`fork`, `exec`, `wait`, `waitpid`, `kill`)
- **Location:** `src/mcmini/real_world/local_linux_process.cpp`, `src/lib/wrappers.c`
- **Key Headers:** `<sys/types.h>`, `<sys/wait.h>`, `<unistd.h>`, `<signal.h>`

**Process Source Factories:**
- `fork_process_source` (`include/mcmini/real_world/process/fork_process_source.hpp`)
  - Creates child processes via `fork()` system call
  - Produces `real_world::local_linux_process` instances

- `multithreaded_fork_process_source` (`include/mcmini/real_world/process/multithreaded_fork_process_source.hpp`)
  - Handles fork in multithreaded environments
  - Special handling for thread safety across fork

## Checkpointing & State Management

**DMTCP (Distributed MultiThreaded CheckPointing):**
- **Purpose:** Create and restore process state snapshots for model exploration
- **Integration Type:** Optional plugin system
- **Plugin Header:** `include/dmtcp.h`
- **Implementation:** `src/mcmini/real_world/dmtcp_process_source.cpp`
- **Key Capabilities:**
  - Event callbacks: `DMTCP_EVENT_INIT`, `DMTCP_EVENT_EXIT`, `DMTCP_EVENT_PRE_EXEC`, `DMTCP_EVENT_POST_EXEC`
  - Fork events: `DMTCP_EVENT_ATFORK_*`, `DMTCP_EVENT_VFORK_*`
- **API Version:** DMTCP_PLUGIN_API_VERSION = "3"
- **Process Source:** `dmtcp_process_source` (`include/mcmini/real_world/process/dmtcp_process_source.hpp`)
  - Produces `real_world::local_linux_process` instances via DMTCP-managed processes

**Shared Memory:**
- **Purpose:** Inter-process communication between McMini coordinator and traced processes
- **System:** POSIX shared memory (`shm_open`, `shm_unlink`)
- **Library:** librt (-lrt linker flag)
- **Implementation:** `src/common/shm_config.c`, `src/mcmini/real_world/shm.cpp`
- **Config:** `include/mcmini/common/shm_config.h`

## Signal Handling

**POSIX Signals:**
- **Purpose:** Process-wide signal interception and management for synchronization
- **Implementation:** `src/mcmini/signal.cpp`, `include/mcmini/signal.hpp`
- **Key Functions:**
  - `signal::install_process_wide_signal_handlers()` - Install custom signal handlers
  - Handles: SIGUSR1, SIGUSR2, SIGCHLD, SIGALRM, SIGCONT, SIGSTOP
- **Headers:** `<signal.h>`, `<bits/sigaction.h>`, `<bits/types/siginfo_t.h>`
- **Constants:** `include/mcmini/constants.hpp`

## Thread Management

**POSIX Threads (pthread):**
- **Purpose:** Concurrent execution model and synchronization primitives
- **Library:** libpthread (-pthread linker flag)
- **Key Abstractions:**
  - Mutexes - `src/mcmini/model/transitions/mutex.cpp`, `include/mcmini/model/objects/mutex.hpp`
  - Condition Variables - `src/mcmini/model/transitions/condition_variables.cpp`
  - Semaphores - `src/mcmini/model/transitions/semaphore.cpp`
  - Thread operations - `src/mcmini/model/transitions/thread.cpp`
- **Process Creation:** Fork-based thread spawning (`src/lib/multithreaded_fork.c`)
- **Synchronization:** Thread queues for coordination (`src/mcmini/Thread_queue.c`)

## Dynamic Library Loading

**Dynamic Linking:**
- **Purpose:** Runtime injection of libmcmini into target processes
- **Library:** libdl (-ldl linker flag)
- **Implementation:** `src/lib/interception.c`, `src/lib/entry.c`
- **Mechanism:**
  - Load `libmcmini.so` into process address space
  - Use `dlsym` to locate and hook pthread/syscall functions
  - Intercept synchronization primitive calls

**Shared Library Target:**
- Output: `libmcmini.so` (compiled from `src/lib/` sources)
- Environment Definition: `MC_SHARED_LIBRARY=1`
- Compiler Flag: `-fPIC` (position-independent code)
- Linking Flags: `-lrt -pthread -lm -ldl`

## Optimization (Optional)

**SCIP Solver:**
- **Purpose:** Linear/mixed-integer optimization for model checking algorithms
- **Integration:** Optional, controlled by CMake flag `MCMINI_USE_SCIP`
- **When Enabled:**
  - Compile definition: `MCMINI_USE_SCIP`
  - Linked to: main `mcmini` executable only
  - Location: `src/mcmini/model_checking/algorithms/`
- **CMake Integration:** `find_package(scip)` with fallback to disabled state
- **Not Used:** Not linked into `libmcmini.so` (shared library)

## Debugging & Development Integration

**GDB Python Scripts:**
- Location: `script/debug-mcmini-child.py`, `script/debug-mcmini-dmtcp.py`
- Purpose: Enhanced debugging experience for model checker processes
- Integration: Custom GDB commands for navigating model checker state

**Compilation Database:**
- Generated by: CMake with `CMAKE_EXPORT_COMPILE_COMMANDS=ON`
- Location: `compile_commands.json` (symlinked from `out/system-*/`)
- Purpose: IDE integration and static analysis tool support (clang-tidy, clang LSP)

## Interception & Hooking

**System Call & Function Wrapping:**
- Location: `src/lib/wrappers.c`
- Purpose: Intercept pthread and system calls from target processes
- Templates: `src/lib/template/loop.c`, `src/lib/template/sig.c`
- Logging Framework: `src/lib/log.c`
- Recording: `src/lib/record.c` - Records interception data

**Entry Point:**
- File: `src/lib/main.c`
- Purpose: Initialization point when libmcmini.so is loaded into process

## Memory Management

**Dynamic Memory:**
- Allocator: Standard `malloc`/`free` (C) and `new`/`delete` (C++)
- Custom allocator: `src/common/mem.c`, `include/mcmini/mem.h`
- Purpose: Consistent memory management across C and C++ code

## Exit & Signal Handling

**Process Exit Management:**
- File: `src/common/exit.c`, `include/mcmini/defines.h`
- Purpose: Graceful shutdown and cleanup of model checker state

**Mailbox Communication:**
- File: `src/common/runner_mailbox.c`
